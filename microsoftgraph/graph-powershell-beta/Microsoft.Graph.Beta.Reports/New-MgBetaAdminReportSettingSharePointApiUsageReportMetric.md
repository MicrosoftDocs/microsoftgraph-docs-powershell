# New-MgBetaAdminReportSettingSharePointApiUsageReportMetric

## SYNOPSIS

## SYNTAX

### CreateExpanded (Default)

```
New-MgBetaAdminReportSettingSharePointApiUsageReportMetric [-ResponseHeadersVariable <string>]
 [-AdditionalProperties <hashtable>] [-Metric <string>] [-OnboardingStatus <string>] [-Break]
 [-Headers <IDictionary>] [-HttpPipelineAppend <SendAsyncStep[]>]
 [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>] [-ProxyCredential <pscredential>]
 [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```
