# Get-MgBetaReportAzureAdPremiumLicenseInsight

## SYNOPSIS

Get the premium license utilization insight for the tenant.
This API returns data about how many premium licenses are entitled and how the associated P1 and P2 features are being used.
The calling tenant must have at least one Microsoft Entra ID P1 or P2 license.
Tenants without a premium license receive a 403 Forbidden response with the missingLicense error code.

## SYNTAX

### Get (Default)

```
Get-MgBetaReportAzureAdPremiumLicenseInsight [-ExpandProperty <string[]>] [-Property <string[]>]
 [-ResponseHeadersVariable <string>] [-Break] [-Headers <IDictionary>]
 [-HttpPipelineAppend <SendAsyncStep[]>] [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>]
 [-ProxyCredential <pscredential>] [-ProxyUseDefaultCredentials]
```
