# Update-MgBetaSolutionBackupRestoreActivityLog

## SYNOPSIS

Update the navigation property activityLogs in solutions

## SYNTAX

### UpdateExpanded (Default)

```
Update-MgBetaSolutionBackupRestoreActivityLog -ActivityLogBaseId <string>
 [-ResponseHeadersVariable <string>] [-ActivityType <string>] [-AdditionalProperties <hashtable>]
 [-Error <IMicrosoftGraphPublicError>] [-EventDateTime <datetime>] [-Id <string>]
 [-PerformedBy <string>] [-ResultStatus <string>] [-ServiceType <string>] [-Severity <string>]
 [-Break] [-Headers <IDictionary>] [-HttpPipelineAppend <SendAsyncStep[]>]
 [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>] [-ProxyCredential <pscredential>]
 [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```

```
Update-MgBetaSolutionBackupRestoreActivityLog -ActivityLogBaseId <string>
 -BodyParameter <IMicrosoftGraphActivityLogBase> [-ResponseHeadersVariable <string>] [-Break]
 [-Headers <IDictionary>] [-HttpPipelineAppend <SendAsyncStep[]>]
 [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>] [-ProxyCredential <pscredential>]
 [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```
