# New-MgBetaIdentitySignInIdentifier

## SYNOPSIS

Create new navigation property to signInIdentifiers for identity

## SYNTAX

### CreateExpanded (Default)

```
New-MgBetaIdentitySignInIdentifier [-ResponseHeadersVariable <string>]
 [-AdditionalProperties <hashtable>] [-IsEnabled] [-Name <string>] [-Break] [-Headers <IDictionary>]
 [-HttpPipelineAppend <SendAsyncStep[]>] [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>]
 [-ProxyCredential <pscredential>] [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```

### Create

```
New-MgBetaIdentitySignInIdentifier -BodyParameter <IMicrosoftGraphSignInIdentifierBase>
 [-ResponseHeadersVariable <string>] [-Break] [-Headers <IDictionary>]
 [-HttpPipelineAppend <SendAsyncStep[]>] [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>]
 [-ProxyCredential <pscredential>] [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```

## DESCRIPTION

Create new navigation property to signInIdentifiers for identity

**Permissions**

| Permission type | Permissions (from least to most privileged) |
| --------------- | ------------------------------------------  |
| Delegated (work or school account) | SignInIdentifier.ReadWrite.All,  |
| Delegated (personal Microsoft account) | Not supported |
| Application | SignInIdentifier.ReadWrite.All,  |
