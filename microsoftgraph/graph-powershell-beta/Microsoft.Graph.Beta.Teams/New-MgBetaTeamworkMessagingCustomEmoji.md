# New-MgBetaTeamworkMessagingCustomEmoji

## SYNOPSIS

Create a new custom emoji in the teamwork messaging of the organization, which adds the custom emoji to Teams for the tenant.
The emoji image is provided as base64-encoded content bytes.

## SYNTAX

### CreateExpanded (Default)

```
New-MgBetaTeamworkMessagingCustomEmoji [-ResponseHeadersVariable <string>]
 [-AdditionalProperties <hashtable>] [-ContentBytes <string>] [-CreatedBy <hashtable>]
 [-CreatedDateTime <datetime>] [-DisplayName <string>] [-Break] [-Headers <IDictionary>]
 [-HttpPipelineAppend <SendAsyncStep[]>] [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>]
 [-ProxyCredential <pscredential>] [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```

### Create

```
New-MgBetaTeamworkMessagingCustomEmoji -BodyParameter <IMicrosoftGraphTeamworkCustomEmoji>
 [-ResponseHeadersVariable <string>] [-Break] [-Headers <IDictionary>]
 [-HttpPipelineAppend <SendAsyncStep[]>] [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>]
 [-ProxyCredential <pscredential>] [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```
