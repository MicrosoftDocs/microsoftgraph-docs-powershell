# Update-MgBetaUserTeamworkSection

## SYNOPSIS

Update the properties of a section in a user's teamwork.
For system-defined sections, only the sortType property can be updated.

## SYNTAX

### UpdateExpanded (Default)

```
Update-MgBetaUserTeamworkSection -TeamworkSectionId <string> -UserId <string>
 [-ResponseHeadersVariable <string>] [-AdditionalProperties <hashtable>]
 [-CreatedDateTime <datetime>] [-DisplayIcon <IMicrosoftGraphSectionDisplayIcon>]
 [-DisplayName <string>] [-Id <string>] [-IsExpanded] [-IsHierarchicalViewEnabled]
 [-Items <IMicrosoftGraphTeamworkSectionItem[]>] [-LastModifiedDateTime <datetime>]
 [-SectionType <string>] [-SortType <string>] [-Break] [-Headers <IDictionary>]
 [-HttpPipelineAppend <SendAsyncStep[]>] [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>]
 [-ProxyCredential <pscredential>] [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```

## DESCRIPTION

Update the properties of a section in a user's teamwork.
For system-defined sections, only the sortType property can be updated.

**Permissions**

| Permission type | Permissions (from least to most privileged) |

| Application | TeamworkSection.ReadWrite.All, Teamwork.Migrate.All,  |
