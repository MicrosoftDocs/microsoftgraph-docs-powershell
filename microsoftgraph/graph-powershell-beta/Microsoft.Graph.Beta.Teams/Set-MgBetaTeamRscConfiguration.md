# Set-MgBetaTeamRscConfiguration

## SYNOPSIS

Update Team RSC configuration for tenant.

## SYNTAX

### Update (Default)

```
Set-MgBetaTeamRscConfiguration -State <MicrosoftGraphRscConfigurationState>
 [-AdditionalProperties <hashtable>] [-Break] [-HttpPipelineAppend <SendAsyncStep[]>]
 [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>] [-ProxyCredential <pscredential>]
 [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```
