# New-MgSecurityIdentityAccount

## SYNOPSIS

Create new navigation property to identityAccounts for security

> [!NOTE]
> To view the beta release of this cmdlet, view [New-MgBetaSecurityIdentityAccount](/powershell/module/Microsoft.Graph.Beta.Security/New-MgBetaSecurityIdentityAccount?view=graph-powershell-beta)

## SYNTAX

### CreateExpanded (Default)

```
New-MgSecurityIdentityAccount [-ResponseHeadersVariable <string>]
 [-Accounts <IMicrosoftGraphSecurityAccount[]>] [-AdditionalProperties <hashtable>]
 [-CloudSecurityIdentifier <string>] [-DisplayName <string>] [-Domain <string>] [-Id <string>]
 [-IsEnabled] [-OnPremisesSecurityIdentifier <string>] [-Break] [-Headers <IDictionary>]
 [-HttpPipelineAppend <SendAsyncStep[]>] [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>]
 [-ProxyCredential <pscredential>] [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```

### Create

```
New-MgSecurityIdentityAccount -BodyParameter <IMicrosoftGraphSecurityIdentityAccounts>
 [-ResponseHeadersVariable <string>] [-Break] [-Headers <IDictionary>]
 [-HttpPipelineAppend <SendAsyncStep[]>] [-HttpPipelinePrepend <SendAsyncStep[]>] [-Proxy <uri>]
 [-ProxyCredential <pscredential>] [-ProxyUseDefaultCredentials] [-WhatIf] [-Confirm]
```
